# tailor studio

## what it is

a desktop app that turns a folder of photos from a clothing shoot into
finished grailed listings. it groups, writes, prices and fills in the form;
i review and publish.

<Slideshow />

## why

i sell clothing on grailed. every listing cost me fifteen to twenty minutes:

- sort the shoot into piles, one per item
- write another description in the same shape as the last
- dig through sold listings to work out what to ask
- type all of it into the form, field by field

## how it works

- **import** — groups the photos by item, and reads the garment, colour and
  condition off them
- **draft** — a title, a description, and a price that starts from pieces
  that actually sold
- **review** — mine. i fix whatever it wasn't sure about
- **fill** — it types the draft into grailed's sell form
- **publish** — mine, always

it's a form-filling assistant, not an auto-poster. i don't want something
posting under my name while i'm not looking.

## what came of it

- a listing takes a few minutes instead of fifteen to twenty
- me, plus a few close friends and family
- no revenue, and not trying for any — it's a personal tool

## how i built it

i built it with claude. i found the problem, scoped it, set the bar for good
enough, and steered the build; claude wrote most of the code. my own
attention went to the accuracy tests for the ai steps, and a sweep across
model configurations to find the cheapest setup that still cleared them.
